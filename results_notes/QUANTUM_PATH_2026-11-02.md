## The data-side method, translated

| Data side | Quantum / theory side |
|---|---|
| Pre-registered fit with a verdict rule | Pre-registered derivation or calculation with a stated PASS/FAIL condition before computing |
| Mirror: rebuild must reproduce the stored χ² | Mirror: the code or algebra must reproduce a known limit **and** a published result before any new number counts |
| Null and known mirrors (e.g. the ΛCDM limit) | Limits: ΛCDM, single field, flat field space, γ → ∞ (no Holst term) |
| Independent datasets (Union3, chronometers) | Independent derivations (two routes to the same number, as λ from GKY and from the α-attractor formula) |
| Look-elsewhere counting | Count every convention choice (signs, origins, normalisations) and say how many were tried |
| Tiers EVIDENCE / HYPOTHESIS / MEANING | Same tiers; a derivation is EVIDENCE only for its own algebra |
| Scales loop until 0 new hits | Same: local, then online, until a round adds nothing |
